# 试标：D13 扫描仪视角，照着窗口一步步做

这份是"照着做"的流程，一行一个动作，后面写**做完你会看到什么**。每个键、每种情况的完整说明在
[annotation_guide.md](annotation_guide.md)。试标的目的是**找出不顺手的地方**：哪一步卡住、哪个
键别扭、哪里看不懂，记下"哪台机器 / 哪一帧 / 当时在做什么"告诉我。

原则（2026-09-19 定）：**四个视角各自从头标，视角内保持一致**；身份（这是 `ram_module.02`）来自
日志，四个视角共用；形状每个视角自己画。现在先只试 `scan`。

---

## 0. 启动

```bat
D:\Anaconda\envs\tda\python.exe -m tda.cli app --annotator chang --desktop 13 --view scan
```

窗口约 1 秒出现。SAM 在后台加载，右下角出现 `SAM ready` 之前，左边的「SAM 点选」「SAM 框选」
是灰的（鼠标停上去会说原因）。

**窗口从左到右**（图：[docs/img/u2b_start.jpg](img/u2b_start.jpg)）：

| 位置 | 是什么 | 怎么用 |
|---|---|---|
| 最左 | 时间轴 | 点一帧跳过去 |
| 左二 | **工具面板** | 上面是工具，中间是笔刷大小，下面是操作。**点按钮 = 按那个键**，按钮上写着键。深色底黄字的是当前工具；**蓝框的是下一步最该按的**；灰的现在不能用，鼠标停上去说为什么 |
| 中间 | 画布 | 正在画某个零件时，顶上有一条黄字横幅写着在画什么、下一步按什么 |
| 右上 | **现在做什么** | 黄底一行 = 下一步按什么；下面 ①–⑤ 是这一帧的五步，▶ 是现在这步；「快捷键」点开是这个模式能用的全部键 |
| 右中 | **任务卡** | 这一帧要画的零件清单（见第 3 节） |
| 右下 | 实例表 | 这一帧画面里有的零件 |

看不懂下一步时，**先看右上角黄底那一行**。

**如果画布下方有一条黄色的"上次未提交的编辑可以恢复"：先点 `恢复` 或 `丢弃`，再动笔。**

## 1. 先到 Steps 模式核对这台机器（5 分钟）

1. 点顶部 `Steps`。→ 中间变成步骤表；右上角写"Steps：核对步骤表和实例表，改完点 Apply"。
2. 只看这几处：

| 步 | 日志 | 要你判断的 |
|---|---|---|
| 2 | `open cover.01`（CPU Fan Cover，导风罩） | 导风罩是**掀开还留在机箱上**，还是**整个拿走**了？拿走了就把这一步的动词从 `open` 改成 `remove`。 |
| 35 | `open cover.02`（Case cover for motherboard screws） | 同上。翻到第 35、36 帧看一眼画面再决定。 |
| 7 | `open drive_latch.01`（SSD shield locker） | 卡扣长在机箱上还是长在 SSD 支架（`drive_cage.01`）上？长在支架上就在实例表里把 `parent` 设成 `drive_cage.01` 并勾 `attached`。 |
| 33 | `open psu_latch.01`（Power module locker） | 同上，对象是电源 `psu.01`。留在机箱上就不用改。 |

3. 改完点 `Apply`（不想要就 `Revert`）。
4. 点顶部 `Annotate`。→ 回到画布，左边工具面板重新出现。

内存卡扣、CPU 压杆已经自动挂在主板上，不用管。实例表里 `ls:` 开头的是旧 Label Studio 草稿，
只作参考。

## 2. 第 42 帧（起点：已经拆完的样子）

1. 画面上有一个**黄色粗虚线框**，框外变暗 —— 这是程序猜的**机箱范围（ROI）**，在等你回答。
   → 右上角写"现在：调好黄框（拖白色小方块），按 Enter 保存"；左边「机箱范围 ROI」是深色的，
   「提交 Enter」有蓝框。
2. 拖四角 / 四边的白色小方块，让框刚好包住机箱（留一点边）；框里按住可以整体挪。
3. 按 `Enter`（或点左边「提交」）。→ 画面缩放到机箱；右上角 ① 打勾，▶ 移到 ②。
   - 差异图和 SAM 的提示框都只在这个框里算，所以框要包住整个机箱。
   - 不想现在管：按 `Esc`。框收起，画布下方留一行 `ROI 未确认`（`确认建议框` / `重画 Shift+R` /
     `不用 ROI`），右上角 ① 变成 ⚠，不挡你做别的。
   - **`R` 不是 ROI**：`R` 是「台面框」，给**已经拆下来、放在台面上的零件**拖框用。ROI 是
     `Shift+R`（左边「机箱范围 ROI」按钮）。
4. 看右边任务卡。顶上一句："第 42 帧（起点，已经拆完的样子）：把这一帧里还看得到的零件都画出来"。
   每一条写着中文名、实例键、日志里的名字、要做什么，右边是状态（`待画`）。例如：
   - `机箱 chassis` — 在这一帧画出它的完整形状
   - `主板螺丝盖板 cover.02` — 日志：Case cover for motherboard screws
   - `电源卡扣 psu_latch.01` — 日志：Power module locker

   鼠标**停**在一条上，画面上会用虚线框标出它大概在哪（它上一帧的形状 / 差异最大处 / 旧草稿），
   只是显示，不会改任何东西。
5. **单击**第一条「机箱 chassis」（单击就行，双击也可以）。→ 马上能看到三处变化
   （图：[docs/img/u2b_editing_empty.jpg](img/u2b_editing_empty.jpg)）：
   - 画布顶上黄字横幅："正在画：机箱 chassis — 用 S 在零件上点一下，或 X 拖框"；
   - 任务卡这一条变黄，状态变成 `✎ 正在画`；
   - 左边「SAM 点选」变成深色（工具自动切到 SAM；你上次用的是「SAM 框选」就切到框选）。
6. 在机箱上**点一下**（左键加一个点，右键减一个点），或按 `X` 在机箱外沿**拖一个框**。
   → 出现黄色半透明的形状；横幅变成"… — Enter 提交 / Esc 放弃"；左边「提交」有了蓝框。
   不满意：按 `C`（或「换候选」）换 SAM 的另一个答案，共 3 个。
7. 边缘不对：`B` 画笔补、`E` 橡皮擦。笔刷大小用左边滑块或数字框，键盘 `[` `]`；数字是图像
   像素，和右下角黄标签的 `r=` 是同一个数。`Shift+F` 填内部空洞，`Shift+D` 删碎块。滚轮缩放，
   **鼠标中键拖动平移**。机箱要画**完整轮廓**（以后被主板、电源盖住的部分也算它的）。
   （图：[docs/img/u2b_editing_pixels.jpg](img/u2b_editing_pixels.jpg)）
8. 按 `Enter`（或「提交」）。→ 这一条变成 `✔ 已完成`，横幅消失，右上角 ▶ 回到 ②，指向下一条。
   如果画布下方弹出"面积异常"：确认没画错就再按一次 `Enter`，否则 `Esc` 回去改。
9. 剩下的条目一样：**单击 → 点一下 / 拖框 → 修边 → Enter**。小零件先滚轮放大再点。
10. 全部 `✔` 后，右上角写"按 Space 确认整帧"，左边「确认整帧」有蓝框。按 `Space`。
    → 自动退到第 41 帧。没通过就不动，原因列在任务卡下面（通常是还有零件没画）。

## 3. 之后每一帧（第 41 → 1 帧）：通常只多一个零件

1. 看任务卡顶上一句："第 j 帧：比第 j+1 帧多了下面这些零件（刚被拆掉的，要把它画回去）"。
   （图：[docs/img/u2b_mid.jpg](img/u2b_mid.jpg)，鼠标停在任务卡那一条上时的虚线框）
2. 找不到零件在哪：
   - 鼠标停在任务卡那一条上 —— 橙色虚线框是差异图给 SAM 的提示框（变化最大的地方），蓝色是
     同类零件的旧草稿，绿色是它在别的帧画过的形状；
   - 按 `D`（「差异图」）看热力图，亮的那块就是它；
   - **按住** `Tab`（或按住「对比上一帧」）闪回上一帧对比，松开回来。
3. 单击那一条 → `S` 在零件上点一下 → `Enter` → `Space`。
4. 第 41 帧会一次多出主板和长在它上面的卡扣（卡片写"跟 motherboard.01 一起装回来的"）：先画主板，
   再画卡扣。

任务卡的图标（鼠标停在任务卡标题上能看到说明）：✚ 要画；✂ 形状变了（例如盖子关上了），画这一帧
的样子，`Ctrl+K` 提交；≡ 只是状态变了，不用画；▭ 零件在台面上，单击这条后在台面上拖框（`R`）；
✔ 这一帧不用画，直接 `Space`。

### 提交时选哪个键

| 情况 | 键 / 按钮 |
|---|---|
| 这个零件的形状一直就是这样（绝大多数情况） | `Enter`「提交」 |
| 只有这一帧特殊：被手挡住、反光、糊了 | `Alt+Enter`「只改这一帧」 |
| 形状从这一帧起真的变了：盖子掀开、线被拨到一边 | `Ctrl+K`「从这帧起新版本」 |
| 画布下方弹出"层级"建议（你画的像素落在别的零件里） | 看提示条，一般 `Enter` 接受 |

画错了 `Ctrl+Z`「撤销」；不想要这次编辑 `Esc`「放弃编辑」。**有未提交的像素时，翻帧、切视图、
确认都会被挡住**（「确认整帧」按钮也是灰的），状态栏提示先 `Enter` 或 `Esc` —— 这是故意的，保证不丢编辑。

### 被挡住 / 看不见的零件

在实例表选中实例后按数字键设可见性：`1` 可见、`2` 部分遮挡、`3` 完全遮挡、`4` 出画面、`5` 太小、
`6` 很小但可见、`7` 运动模糊。手或工具挡在画面里：「遮挡」（`O`）把手涂出来。

## 4. 走完之后：Review

1. 点顶部 `Review`。→ 左边工具全灰（复查模式画布只读，只有「差异图」能用）；右上角写复查的键。
2. 右下四个队列：`Conflicts`（`K` 保留旧的 / `N` 采用新的）、`Needs review`、`Missing shape`、
   `Unexplained`（确认时还有没人认领的变化区域，多半是漏标了零件）。
3. 选中一条按 `R` 回到那一帧返工，或 `Enter` 接受。

## 5. 收工与导出（可选）

直接关窗口：程序会保存、备份数据库到 F 盘的 `TDA_backups`、释放锁。如果提示"无法提交，已取消
关闭"，再按一次保存即可。

```bat
D:\Anaconda\envs\tda\python.exe -m tda.cli status --desktop 13
D:\Anaconda\envs\tda\python.exe -m tda.cli check --desktop 13 --view scan
```

## 6. 这次改掉的几件事（和第二次试用时不一样）

- **工具面板**：所有工具和提交 / 确认 / 撤销都有按钮，按钮上写着键；点按钮和按键完全一样。
- **现在做什么**：右上角永远写着下一步按什么，▶ 指着这一帧五步里的当前一步。
- **任务卡看得懂了**：每条有中文名、日志里的名字、一句要做什么和状态；**单击就开始画**；
  鼠标停在一条上会标出它大概在哪。
- **开始画看得见了**：画布顶上横幅写着"正在画：…"，任务卡那条标 `✎ 正在画`，空的零件自动
  切到 SAM。上次"双击了没反应"其实已经开始编辑了，只是屏幕上几乎没有变化。
- **笔刷大小可以拖**：左边滑块 / 数字框 / `[` `]` / 光标圆圈 / 黄标签 `r=` 是同一个数。
- **`R` 和 `Shift+R` 名字分开了**：`R` 台面框（已拆下、放在台面上的零件），`Shift+R` 机箱范围 ROI。
- 之前的规矩照旧：SAM 只做加法（再点再框都**并**进去，减像素只有 `E` 和右键负点）；擦掉的像素
  不会被 SAM 加回来；ROI 不会无声消失。

## 7. 已知情况

- `Esc` 是分层的：面积提示 → ROI 矩形 → 台面框 → 编辑层，一次退一层。
- 按了键没反应：多半是焦点在某个输入框里，点一下画布再按，状态栏也会提示一次。
- D64 的自动 ROI 不对，要手动 `Shift+R`。D63 第 31→32 步机箱被转了 90°：画布下方会出现
  "可能的机箱移动"提示条，点接受（或 `Ctrl+Shift+B`）；切分后另一段的形状要重画，ROI 重新问。
- OAK / RealSense 视角（`F2`–`F4`）流程和 `scan` 一样，每个视角各自从头画。
- `Shift+A`：编辑某个零件时把鼠标指在它上面按一下，旧 Label Studio 草稿以淡蓝色预览出现，
  `Enter` 采纳、`Esc` 取消；`Shift+C`：换差异图给 SAM 的提示框。
- 请顺手记时间：一台机器 scan 视角从头到尾用了多久、哪类零件最费时间——排期要用。
