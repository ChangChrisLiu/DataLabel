# 第一次试标：D13 扫描仪视角，从头到尾走一遍

这份是"照着做"的流程；每个键、每种情况的完整说明在 [annotation_guide.md](annotation_guide.md)。
试标的目的不是标得多，而是**找出不顺手的地方**：哪一步卡住、哪个键别扭、哪里看不懂，记下
"哪台机器 / 哪一步 / 当时在做什么"告诉我。

原则（2026-09-19 定）：**四个视角各自从头标，视角内保持一致**；不指望把一个视角的标注自动
转到另一个视角。身份（这是 `ram_module.02`）来自日志，四个视角共用；形状每个视角自己画。
现在先只试 `scan`。

---

## 0. 启动

```bat
D:\Anaconda\envs\tda\python.exe -m tda.cli app --annotator chang --desktop 13 --view scan
```

窗口约 1 秒出现，SAM 在后台加载（右下角状态栏出现 `SAM ready` 后 `S` / `X` 才可用）。
窗口里任何时候按 `?` 看全部快捷键。

**如果画布下方有一条黄色的"上次未提交的编辑可以恢复"：先点 `恢复` 或 `丢弃`，再动笔。**

## 1. 先到 Steps 模式核对这台机器（5 分钟）

点顶部 `Steps`。上面是步骤表，`Instances` 页签是实例表，下方 `Open questions` 是程序拿不准、
要你回答的问题。D13 的日志一共 42 步，要看的只有这几处：

| 步 | 日志 | 要你判断的 |
|---|---|---|
| 2 | `open cover.01`（CPU Fan Cover，导风罩） | 导风罩是**掀开还留在机箱上**，还是**整个拿走**了？拿走了就把这一步的动词从 `open` 改成 `remove`。 |
| 35 | `open cover.02`（Case cover for motherboard screws） | 同上。翻到第 35、36 帧看一眼画面再决定。 |
| 7 | `open drive_latch.01`（SSD shield locker） | 这个卡扣长在机箱上还是长在 SSD 支架（`drive_cage.01`，第 11 步拆走）上？长在支架上就在实例表里把它的 `parent` 设成 `drive_cage.01` 并勾 `attached`，它会跟着支架一起离开。 |
| 33 | `open psu_latch.01`（Power module locker） | 同上，对象是电源 `psu.01`（第 34 步拆走）。留在机箱上就不用改。 |

内存卡扣（`ram_latch.01–04`）和 CPU 压杆已经自动挂在主板上，不用管。
列表里 `ls:` 开头的实例是旧 Label Studio 的草稿，只作参考，不用画、不用删。

改完点 `Apply`（不想要就 `Revert`），再点顶部 `Annotate` 回到画布。

## 2. 第一帧：回答 ROI（机箱范围）

第一次打开这台机器的这个视角时，画面上会出现一个**黄色粗虚线矩形**，框外的部分压暗 ——
那是程序猜的机箱范围（ROI），它**在等你回答**。画布下方的提示条把这三件事写清楚了：

- **它是什么**：这一段（同一个位姿段）的机箱范围，存在 `pose_segment.roi` 里。
- **干什么用**：**帧间差异图和喂给 SAM 的框提示都只在这个矩形里算**——框外的台面、胶带、
  反光会制造一堆假的"变化"，把真正的零件淹掉；画面的缩放也以它为准。所以框歪了，后面每一帧
  的 SAM 提示都会跟着变差。
- **怎么答**：
  - 矩形四角和四条边上各有一个**白色小方块**，拖它改大小（鼠标移上去光标会变成双向箭头）；
    在框**里面**按住可以整体挪动；在框外的空白处拖动则是重新画一个。
  - 调到刚好包住机箱（留一点边）后按 **`Enter` 保存**，画面会自动缩放到它。
  - 还不想管就按 **`Esc` 跳过**。矩形会收起来，但提示条会留下一行 `ROI 未确认`，带三个按钮：
    `确认建议框`（直接存程序猜的那个）、`重画 Shift+R`、`不用 ROI`（这一段就不要了，以后
    不再问）。它不挡你做任何事，也不会再自己弹出来。
  - 直接双击任务卡开始画也可以：矩形让位给画笔，那一行 `ROI 未确认` 还在，随时可以回答。

状态栏右侧一直写着 `ROI ✓` / `ROI 未确认` / `无 ROI`。存好之后矩形变成一条**细虚线**留在画面
上（和其它图层一样，按 `A` 可以关掉），`F` 缩放到它，`Shift+R` 重画（编辑层有没提交的像素时
会被挡，先 `Enter` 或 `Esc`）。

## 3. 起点帧（第 42 帧，主板已拆走的空机箱）

倒序标注从最后一帧开始。右上角任务卡列出这一帧要画的东西，机箱排第一。

1. **双击任务卡第一条 `chassis`**。状态栏显示 `editing chassis`。
2. 按 `X`，在机箱外沿拖一个框 → SAM 给出掩码；不满意按 `C` 换候选（共 3 个）。
   - 或按 `S` 在机箱上点一下（左键加点，右键减点）。
3. 边缘不对的地方：`B` 画笔补、`E` 橡皮擦，`[` `]` 调笔刷；`Shift+F` 填内部空洞，
   `Shift+D` 删碎块。滚轮缩放，**鼠标中键拖动平移**。
   机箱要画**完整轮廓**（amodal）：以后被主板、电源盖住的部分也算它的，层级由程序管。
4. **`Enter` 提交**。如果弹出"面积异常"的提示条，那只是提醒：确认没画错就再按一次 `Enter`。
5. 任务卡上这一条被划掉，下一条自动高亮。剩下的（留在机箱上的盖板、卡扣）同样处理：
   双击 → `S` 点一下 → 修 → `Enter`。小零件先滚轮放大再点。
6. 全部划掉后按 **`Space` 确认整帧**。通过了会自动退到第 41 帧；没通过不会动，原因写在
   任务卡下面的 `Problems` 里（通常是还有实例没形状）。

## 4. 之后每一帧（第 41 → 1 帧）：每帧通常只多一个零件

站在第 j 帧，任务卡说的就是"这一帧比上一帧（j+1）多出来的那个零件"——也就是"把刚拆掉的
装回去"。

- 第 41 帧：`motherboard.01` 回来了，同时带回长在它上面的 `ram_latch.01–04` 和
  `cpu_socket_lever.01`（卡片逐条列出，主板排在前面）。先画主板，再画卡扣。
- 第 40 → 36 帧：每帧多一颗主板螺丝。按 `D` 打开差异热力图，亮的那块就是它；虚线框是程序
  准备喂给 SAM 的范围。双击卡片条目 → `S` 点螺丝 → `Enter` → `Space`。
- **按住 `Tab`** 闪回上一帧对比（松开回来），找不到零件在哪时最有用。
- 卡片图标含义：✚ 要画；✂ 形状变了要新版本（双击后画新形状，`Ctrl+K` 提交）；
  ≡ 只是状态变，不用画；▭ 零件在台面上，双击后按 `R` 拖框；✔ 没东西可画，直接 `Space`。

### 提交时选哪个键

| 情况 | 键 |
|---|---|
| 这个零件的形状一直就是这样（绝大多数情况） | `Enter` |
| 只有这一帧特殊：被手挡住、反光、糊了 | `Alt+Enter`（只改这一帧） |
| 形状从这一帧起真的变了：盖子掀开、线被拨到一边 | `Ctrl+K`（从这帧起新版本） |
| 弹出"层级"建议（你画的像素落在别的零件里） | 看提示条，一般 `Enter` 接受 |

画错了 `Ctrl+Z`；不想要这次编辑 `Esc`。**有未提交的像素时，翻帧、切视图、确认都会被挡住**，
状态栏会提示先 `Enter` 或 `Esc`——这是故意的，保证不丢编辑。

### 被挡住 / 看不见的零件

选中实例后按数字键设可见性：`1` 可见、`2` 部分遮挡、`3` 完全遮挡、`4` 出画面、`5` 太小、
`6` 很小但可见、`7` 运动模糊。手或工具挡在画面里：按 `O` 用遮挡画笔把手涂出来。

## 5. 走完之后：Review

点顶部 `Review`，右侧四个队列：`Conflicts`（你后来的修改和已确认的帧对不上：`K` 保留旧的 /
`N` 采用新的；`Ctrl+Z` 关不掉冲突）、`Needs review`、`Missing shape`、`Unexplained`
（确认时还有没人认领的变化区域，多半是漏标了零件）。选中条目按 `R` 回到那一帧返工。

## 6. 收工与导出（可选）

直接关窗口：程序会保存、备份数据库到 F 盘的 `TDA_backups`、释放锁。如果提示
"无法提交，已取消关闭"，再按一次保存即可。

```bat
D:\Anaconda\envs\tda\python.exe -m tda.cli status --desktop 13
D:\Anaconda\envs\tda\python.exe -m tda.cli check --desktop 13 --view scan
D:\Anaconda\envs\tda\python.exe -m tda.cli export-coco --help
```

还有未解决的冲突或排队的复检时，导出会拒绝并告诉你原因。

## 7. 已知情况

- `Esc` 是分层的：面积提示 → ROI 矩形 → 台面框 → 编辑层，一次退一层。
- **SAM 只做加法**：再框一次、再点一个点，新的掩码是**并**进已有像素的，不会抹掉你手画的
  或上一次的结果。要减像素只有 `E` 橡皮和 SAM 的右键负点两条路。
- **当前是哪个工具**看状态栏那个黄标签（`工具：画笔 B` / `工具：SAM 框选 X`），画布上的光标
  也跟着变：画笔和橡皮是和笔刷一样大的圆圈（橡皮是白色虚线），SAM 和各种框是十字。按了键
  没反应、标签也没变，多半是焦点在某个输入框里——点一下画布再按。
- D64 的自动 ROI 不对，要手动 `Shift+R`；D63 第 31→32 步机箱被转了 90°，位姿段的手动切分
  还在做（Plan B 第一批），先别标 D63。
- OAK / RealSense 视角（`F2`–`F4`）现在能打开看，但 12 MP 图上的速度和分视角位姿段还没做完，
  正式标注等 Plan B 第一批。
- 请顺手记时间：一台机器 scan 视角从头到尾用了多久、哪类零件最费时间——排期要用。
