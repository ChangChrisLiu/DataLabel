# Teardown Annotator 标注手册

面向每天标注 6 小时的人。全文假设 Windows、数据盘 `D:`、原始盘 `F:` 只读。

---

## 1. 启动

```bat
rem 接着上次的机器和帧继续；也可以显式指定
D:\Anaconda\envs\tda\python.exe -m tda.cli app --annotator chang
D:\Anaconda\envs\tda\python.exe -m tda.cli app --annotator chang --desktop 13 --view scan --step 42
```

- 只有 `--annotator` 必填（也是锁的持有人）。其余省略时按 `tda_app.ini` 记的**上次机器 /
  视图 / 步骤**开；第一次用开有帧的最小编号机器 `scan` 的**最后一张有图像的帧**。
- 先取**单人锁**再开数据库。别人开着时弹框写明持有人和时间，以退出码 3 退出，数据库没被
  打开过（只读了锁文件 `<db>.lock`）。
- SAM 在窗口显示**之后**才后台加载，第一帧 0.7 秒就能看到；没有模型只是 `S` / `X` 不可用（§8）。
- 窗口大小、面板布局也在 `.cache\tda_app.ini`，日志在 `.cache\logs\tda_app.log`（都在
  `D:\DataSet` 下，不写注册表和 C 盘）。

**关闭时**依次：停后台线程 → `session.save()` → `session.close()`（等复检线程收尾）→ 备份到
`backup_dir` 并校验非空 → 放锁。备份失败只告警，不拦关窗口。有**没提交的编辑**时先弹框问：
提交 / 放弃 / 取消。

---

## 2. 三种模式

顶部标签页切换。**复查模式下画布只读**：不接工具，点画布只提示"按 R 返工"（Enter/Esc 属于
标注模式，那里开始的编辑没法提交）。

| 模式 | 中间显示 | 什么时候用 |
|---|---|---|
| **Steps（S1 步骤核对）** | 步骤表 + 实例表 + 约束图 | 核对步骤、动作、目标实例，拆分复合行，删没人引用的实例，补约束边（§5.6）。`Apply` 后会话在**同一帧**重开；有未保存修改时切走会先问。 |
| **Annotate（标注）** | 画布 | 主战场。倒序一帧帧往前画。 |
| **Review（复查）** | 只读画布 + 右侧队列 | 四个队列见第 6 节。`Enter` 接受、`R` 返工、`K`/`N` 处理冲突。 |

## 3. 倒序标注一步的流程

标注方向和拆解相反：从最后一帧往回走，等于"把刚拆下来的零件一个个装回去"。
`PgDn` 是"前进"（k−1），`PgUp` 后退。

**关键：任务卡永远说"眼前这一帧要画什么"。**
站在第 j 帧时，卡片列的是 j+1 到 j 之间的变化 —— 在 j+1 已拆下、j 还装着的零件，所以每条都能
**就在这张图上**画出来。`Tab` 闪回的就是 j+1（`Shift+Tab` 另一侧），差异图也是拿当前帧和 j+1
比的，高亮那块正是卡片让你画的零件。（j+1 缺帧时跳到再上一帧，卡片就跨了不止一个动作，状态栏
会说。）

1. **看任务卡**（右上）。会话按相邻两帧的状态差自动生成，每条写明要做什么：
   - ✚ `add_shape`：零件在 k−1 还在机箱里，把它画回去；
   - ✂ `split_keyframe`：形状变了（盖子打开→关上、接头拔掉→插上），要新的一版形状；
   - ≡ `state_only`：形状不变，只有状态变（螺丝拧松→拧紧），不用画；
   - ▭ `add_bench_box`：零件拆到台面上了，双击这条把框工具武装给它（不开编辑层）；没武装时
     `R` + 拖框只认**这一帧确实在台面上**的选中实例，换帧/视图/机器/模式/工具或 `Esc` 解武装；
   - ⌫ `remove_bench_box`：零件回到机箱里，台面框到此为止；
   - ✔ `confirm`：这一帧没什么可画（重复帧、失败帧），一个键确认。
   做完的条目划掉，第一条没做的自动高亮。

2. **双击任务卡条目**开始编辑。该实例当前的完整（amodal）形状进编辑层，黄高亮。

3. **画**。两条路，常混用：
   - **SAM**：`S` 点提示、`X` 框提示。差异图把"变化最大、且没被别的条目解释掉"那块的外框自动
     喂给 SAM（点+框实测 IoU 0.76，单点 0.24），画面上虚线框标出用的是哪块；框不对按
     `Shift+C` 换下一个（第 1 个永远是默认那块，十字是建议点的位置）。
   - **手改**：`B` 画笔、`E` 橡皮，`[` `]` 调笔刷大小（可长按；非美式键盘可能要配合右 Alt，
     按不出来用 `?` 查键名）。`Shift+F` 填空洞、`Shift+D` 删小碎块，各算一笔。
   - **旧草稿**：编辑某实例时把鼠标停在那个零件上按 `Shift+A`，光标下的 Label Studio 旧标注
     以幽灵色显示（只显示，草稿永不被改）：`Enter` 并入编辑层算一笔，`Esc` 只撤幽灵。
   - **SAM 只做加法**：再框一次、再点一个点，结果**并**进层里，绝不抹掉你手画的、采纳的草稿
     或上一次的结果；减像素只有橡皮 `E` 和右键负点。
   - **提示点只属于当前零件、当前帧**：提交 / `Esc` / 撤销 / 换零件 / 换帧都清空（第一个点给
     3 个候选，`C` 轮换）；手工改过 SAM 结果后 `C` 不再轮换，状态栏会说明。

4. **`Enter` 提交**。会话判断范围：普通情况按 `keyframe` 写进去；若判断是**层次关系**而不是
   轮廓问题（你画的像素落在另一个实例形状里），画布下方弹**非模态**提示条，写明建议范围、会写
   什么、影响帧数，`Enter` 接受、`Alt+Enter` 只改这一帧、`Ctrl+K` 从这一帧起拆分。`Esc` 放弃。

5. **`Space` 确认整帧**。通过了自动退到 k−1；没通过不动，问题列在任务卡里（比如该在机箱里的
   实例还没形状）。这一步还把仍"没人解释"的差异区交给复查队列的 `unexplained`。

`Ctrl+Z` / `Ctrl+Y` 撤销重做，画笔笔画、SAM 应用、提交都在同一条历史里。

**不会丢东西的规矩**（只在状态栏提示，不弹框）：

- 编辑层有没提交的像素时，**每一件离开这一帧的事都会被挡住**，提示"未提交的修改：Enter 提交 /
  Esc 放弃" —— 翻页、点时间轴 / 复查队列、切视图 / 机器 / 模式、双击另一个实例，还有容易忘的：
  `Space` 确认（**含任务卡的 `Confirm  Space` 按钮**）、`F5`、复查 `R` 返工、S1 `Apply` 重载、
  恢复 sidecar、`Shift+R`、`Ctrl+Shift+B`。按 `Enter` / `Esc` 再走；被挡住时 sidecar 立刻落盘。
- 任务卡四个按钮和它们的键**完全等价**（`Commit ⏎` 也先问建议范围，不是一律 `keyframe`）。
- **没选中实例就开始画**：自动认领任务卡第一条没做完的"画形状"条目（状态栏写
  `editing <实例>`）；没有可认领的就原样撤销并提示。
- 每一笔画完 0.3 秒后未提交的编辑层写进 sidecar（§8），提交或 `Esc` 后删除；写不进去时状态栏
  挂"崩溃保护已失效"，看到就尽快提交。

**平移**：**中键拖拽**（`Space` 是"确认整帧"），滚轮缩放，点缩略图也行。
**实例表**只列这一帧还在画面里的实例，勾 `Removed` 看拆走的（灰色只读）。**按住 `Tab` 画布是
对照帧**（松开回来，视角不动），工具全停，状态栏写明对照哪一步。

## 4. 四种编辑范围，分别什么时候用

| 范围 | 键 | 含义 | 什么时候用 |
|---|---|---|---|
| `keyframe` | `Enter` | 改当前生效的关键帧，影响它覆盖的整段 | **默认**。零件的形状一直就是这样，只是之前画错了。 |
| `frame_override` | `Alt+Enter` | 只改这一帧 | 这一帧被手挡住了 / 有反光 / 这一帧特别糊，别的帧没问题。 |
| `split` | `Ctrl+K` | 从这一帧起产生新的一版形状 | 形状**真的**从这里开始变了：盖子打开、线束被拨到一边、风扇换了角度。 |
| `zorder:above:B` | `Enter` 接受建议 | 记录"A 盖住 B"，**并把你新画的像素写进 A 的形状** | 你往 B 上画了 A 的一块：那块本来就不在 A 的形状里，只改层级会把它丢掉。 |
| `split+zorder:above:B` | 建议出现时按 `Ctrl+K` | 同上，但形状是**从这一帧起的新版本**，层级照样记 | 形状真的从这里变了，而且新画的部分被 B 盖着。少了层级你会看到"提交了但画面没变"。 |
| `zorder:below:B` | `Enter` 接受建议 | 只记录"B 盖住 A"，**不缩小 A 的形状** | 你擦掉的正是 A、B 重叠处：A 那块还在，只是被 B 挡住了。 |

范围条写明三个键各写什么。选错了 `Ctrl+Z` 连层级带形状退回；**但**影响到已确认帧会进冲突队列。

## 5. ROI（机箱范围）

第一次打开一个机器 / 视图 / 位姿段时，程序自动框出机箱，**等你回答**，画布下方的提示条写明
它是什么、干什么、怎么答。它不只是取景：**差异图和 SAM 提示框都只在框内算**（台面边缘的伪
差异会淹没真变化），画面也按它缩放。

- 拖四角 / 四边的白方块改大小（光标会变），框里按住整体移动，空白处拖动重画，框外压暗的就是
  不算的部分。**框开着时 `Enter` / `Esc` 归它管**，都不动编辑层。
- **`Enter` 保存**进 `pose_segment.roi`；**`Esc` 先跳过** —— 矩形收起来，问题还在：提示条变成
  一行 `ROI 未确认` 带 `确认建议框` / `重画 Shift+R` / `不用 ROI`，不挡操作也不再自己弹。双击
  实例开始画也一样。**`不用 ROI`** 是"这段不要框"，记下不再问（重切位姿段会重新问）。
- 状态栏常驻 `ROI ✓` / `ROI 未确认` / `无 ROI`；存好的框画成细虚线，同 `A` 开关，`F` 缩放到
  它，`Shift+R` 重画（编辑层脏时挡）。

## 5.5 位姿断点（`Ctrl+Shift+B`）

位姿段按视角独立：断点 = `reorient` 步（四视角共用）∪ **本视角的断点**。相机被碰过、机箱挪过
之后形状不能沿用，`Ctrl+Shift+B` 从当前帧起新开一段：对话框并排放两帧，写明几个形状跨过断点，
勾选框决定要不要复制到前一段（位移 < 25 px 默认勾上；不勾前面的帧就变"缺形状"，提示按新位姿
重画；**手动断点永远不预勾**，你正是嫌形状对不上才断的）。相机审计提议的断点在该帧（仅标注
模式）弹非模态提示条：`Tab` 对比两帧再按 接受 / 拒绝 —— 拒绝的下次导入不再提议；接受后再
拒绝会合并回去，这就是断点的撤销（`Ctrl+Z` 不管结构性编辑；**断开后撤销历史清空**，先确认
再断）。层级和成对覆盖复制到新一段；**两个 ROI 只有实测位移 < 25 px 才复制**，
190 px、90° 或手动断点的另一侧会重新弹 ROI 框。时间线上每个已接受的断点画一条细横线；受影响
的已确认帧进复查队列，形状一字节不改。合并时层级以"保留参考帧那段"为准（另一段独有的层追加
末尾，不丢），换位置的层对与其余损失写进 `pose_issues`。

## 5.6 约束图（Steps 第三页 Relations）

这台机器的硬约束图（§7）。每行一条边，第一列**来源**决定你能做什么：`rule` 由实例属性推出，
每次 `Apply`/`constraints` 重推，**不能改删**，右键只有 接受 / 拒绝 —— 决定存成同一条边的
`override` 行，重跑照样算数，再右键可撤销；`manual` 是你写的边，重跑不变，也只有它能删。
规则不再推出那条边时决定变 `*_orphan`（失效），右键 保留为手动边（写理由）/ 清除。

加边：选 从（目标）/ 类型 / 到（阻挡方）/ 强度 / 方式，写句理由，`Add edge`。只有 `blocked_by`
填方式，它决定挡什么：`cable_tension` 只挡 remove，`physical_path` 还挡 displace，
`tool_access` 全挡。端点不存在或是 `ls:` 草稿、自环、与已有边重复、**required** 边造成**死锁**
（一圈动作互相等，谁都做不了；不是零件成环）的编辑当场拒绝并写明那圈动作；`recommended`
只是顺序偏好，矛盾了提示一句、规划时忽略。

表下是 `constraints --validate` 的同一份校验，加一行死锁/死路检查（都进"待确认问题"，双击跳到
那条边；死锁标红拦 Apply，**死路**只提醒：某条边没有动作能解除，多半缺了个零件）。
`missing edge?` 是"这步失败了，可图里没拦路的东西"，正是该补 `blocked_by` 的地方，补对当场
消失。编辑都暂存，和步骤表一起 `Apply`（同一事务，连规则一起重推；边集真变了才重盖
`graph_version`）。改实例表可能让规则边复活并和手动边死锁：**这种 Apply 整个拒绝并回滚**，
按提示删/改手动边或拒绝那条规则边；`Revert` 全丢掉。

## 6. 复查队列

Review 模式右侧四个标签页，页签上带数量：

- **Conflicts 冲突**：你的编辑和某个已冻结的帧对不上。`Keep old` 丢弃编辑、`Accept new` 接受
  并重新冻结受影响的帧。被后来的改动**顶掉**的冲突说"已被覆盖，重新入队"并刷新（不是拒绝，
  是让你看新的那条）；真被拒绝时理由在状态栏。
- **Needs review 待复查**：要第二双眼睛看的帧。
- **Missing shape 缺形状**：编译器认为该有形状却没有的实例。
- **Unexplained 未解释差异**：确认帧时没人认领的变化区域，多半漏标了零件。

回车 = **打开选中条目那一帧并确认它**（不是屏幕上这帧）；`R` 退回重做。复查不扫全视图。

`F5` 只重编译**这一帧**并把失败/积压的复检**重新排队**（后台做，状态栏报数量），按下去是
瞬间的。整视图交给命令行：

```bat
D:\Anaconda\envs\tda\python.exe -m tda.cli check --desktop 13 --view scan
```

导出（`export-coco` / `export-vlm`）先做同样的重编译；还有帧排队等复检就拒绝，叫你先跑 `check`。

## 8. 常见问题

**打不开，提示被锁住。**
`<db>.lock` 写着持有人和时间，对方关窗口就释放。崩溃留下的残留锁过期后下次启动自动接管；
急用可手动删，**前提是确认没有第二个人在标**。

**某一步没有图像。**
画布写"本视图在该步骤没有图像"，工具全禁用。这一逻辑步骤仍在时间轴上（状态机和形状锚点都要
经过它），只是这个视图没拍到；翻页自动跳过，点时间轴才停在上面。

**提交之后出现冲突。**
这次编辑改变了某个已确认帧的结论，去 Review 的 Conflicts 队列按§6 处理。

**程序崩了，刚画的没提交。**
每一笔画完把编辑层写到 `D:\DataSet\.cache\sidecar\<你的名字>\`，按"机器/视图/步骤/实例"分
文件。下次打开同一帧或再编辑该实例时画布下方出现"上次未提交的编辑可以恢复"，`恢复` 拿回来、
`丢弃` 扔掉；实例已被 S1 删掉时自动清理。已提交的内容即时落盘。

**内存卡扣、CPU 压杆跟着主板走。** 它们长在主板上，日志只会 `open`，从不单独拆，程序按
"挂在主板上"处理：主板被拆走那步它们一起离开机箱，任务卡不再要形状（勾 `Removed` 能看到它们
和主板一起灰着）；往回走到主板还在的那帧，卡片写
`Draw ram_latch.01 (ram_latch) on this frame, back in with motherboard.01`，照画即可。
某个卡扣不跟主板走时，**去实例表取消 `attached` 或把 `parent` 改指别处**：只清空 `parent`
不算数，下次推断会把主板填回去。（主板没拆走的机器每帧照画。）

**任务卡让我画一个已经不在画面里的盖子。** 多数日志把这步写成 `open cover`，实际整个拿走了，
状态机只好按"打开但仍在机箱里"算，于是每帧都还要它。回 S1 把那步动词改成 `remove`，**改一处
整条序列跟着变**。（`ram_latch` / `cpu_socket_lever` 的动词框里没有 `remove` 是故意的：它们
不靠动词离开。）

**SAM 用不了。** 状态栏写明原因（缺权重 / 没有 CUDA / 没装 `sam2`）；权重路径来自
`paths.yaml` 的 `weights_dir`。

**想知道还差多少。**
顶部机器下拉框写着 `D13 <品牌> [已确认/总帧数]`，确认一帧、换视图或后台复检后即更新；
`tda.cli status --desktop 13` 给分视图统计。
